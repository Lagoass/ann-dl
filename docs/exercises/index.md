| [Data](data/index.md) | 10/set | :material-check-circle: entregue |

| [VAE](vae/index.md) | 22/out | :material-progress-helper: não iniciado |

[regras de submissão](https://insper.github.io/ann-dl/2026.2/exercises/submission/){:target="_blank"}:
`index.md` com o relatório, `code/` com os scripts que realmente rodei (incluídos no
relatório via `--8<--`) e `figures/` com as imagens commitadas.

[Raciocínio](../raciocinio/index.md).
