# Raciocínio

Esta seção registra o **passo a passo do meu pensamento** em cada entrega: as decisões que
tomei, as alternativas que descartei e por quê. Não é parte exigida do relatório — é o meu
registro de processo, pelo mesmo motivo que a página do projeto tem um registro de decisões:
*"é o que permite reconstruir o raciocínio na prova"*.

Todas as notas da disciplina estão sujeitas a defesa oral, e a Prova Final (24/nov) vale 60%
da nota individual. Um relatório mostra **o que** foi feito; esta seção guarda **por que**
foi feito assim — que é exatamente o que uma defesa pergunta.
