Este site reúne as entregas individuais e em equipe da disciplina de Redes Neurais
Artificiais e Deep Learning. Cada entrega tem sua própria página, com a descrição da
abordagem, o código comentado, as figuras geradas e a análise dos resultados.

!!! tip "Como este site é atualizado"

    O conteúdo é escrito em Markdown na pasta `docs/` e publicado automaticamente pelo
    GitHub Actions a cada `push` na branch `main`. Detalhes em
    [Sobre este site](setup/index.md).
